# Stockfish 19 Lite (WebAssembly)

`stockfish-19-lite-single.js` and `stockfish-19-lite-single.wasm` are unmodified files from the [`stockfish` npm package](https://www.npmjs.com/package/stockfish) version 19.0.0, a WebAssembly build of [Stockfish](https://stockfishchess.org/) by Nathan Rugg and Chess.com ([source](https://github.com/nmrugg/stockfish.js)).

Stockfish is free software licensed under the GNU General Public License v3. See `Copying.txt` for the license. Source code for this build is at https://github.com/nmrugg/stockfish.js/tree/v19.0.0, and Stockfish's own source code is at https://github.com/official-stockfish/Stockfish.

The page runs this engine in a Web Worker for the 2400-rated opponent and for game review.
